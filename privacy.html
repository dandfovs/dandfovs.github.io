Privacy Policy — claude gmail

Last updated: October 29, 2026

claude gmail is a personal application used only by its owner to access the owner's own Gmail accounts.

Data accessed

With your consent, the app uses the Gmail API (scope gmail.modify) to search, read, draft, send and label email messages.

How data is used and stored

  • All processing happens locally on the owner's computer.
  • OAuth tokens are stored only in a local folder on that computer.
  • No data is sold, shared with third parties, or used for advertising.
  • No data is sent to any server operated by the app's developer.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke access at any time at myaccount.google.com/permissions.

Contact the owner via GitHub.
